REPAIR GENIUS WEBSITE - DEPLOYMENT GUIDE

Included:
index.html - page structure and text
style.css - colours, layout, responsiveness and animations
app.js - menus, repair finder, forms, search and other interactions
assets/ - all website images

DEPLOY
1. Extract this ZIP.
2. Upload index.html, style.css, app.js and the assets folder together to your hosting web root (often public_html).
3. Keep index.html at the root and preserve filenames and folder structure.
4. Open your domain and check desktop/mobile layouts, menus and enquiry actions.

No build command, package installation or framework is required. This is a static website. Netlify, Cloudflare Pages, GitHub Pages or any standard HTML hosting can serve these files. For drag-and-drop hosting, upload the extracted folder containing index.html.

CUSTOMISE
Edit copy/contact details in index.html. Edit colours and animations in style.css. Edit finder choices, FAQs and interaction behaviour in app.js. Keep app.js: the interactive features require JavaScript.
The font is loaded from Google Fonts; a system sans-serif fallback is provided.

CURRENT LIMITATIONS
Forms prepare email drafts. Visitors must send these in their own email app. Forms do not submit to a server or confirm appointments. Online form delivery, spam protection, live scheduling and checkout need backend integrations.
Review cards are clearly labelled placeholders; replace with genuine verified reviews before public launch.
Illustrative device photos do not imply actual shop photography or current stock.
Browser visual and interaction testing remains outstanding.

All website images are included. The project contains no hosting credentials or private source-repository configuration.
